# jasonvasquez.net

Personal site and CV. Single static page, no build step.

- `index.html` is the whole site. Edit it directly.
- `fonts/` holds Geist and Geist Mono (SIL OFL), self-hosted and subset to Latin so the page makes no third-party requests.
- `CNAME` tells GitHub Pages to serve at `jasonvasquez.net`. Do not delete it.
- `.nojekyll` skips Jekyll processing.

Deploys automatically from `main` via GitHub Pages.
